# v0.1.0 pilot

The first public release of Nexus: a single binary that fronts
every LLM API call behind a gateway, carries an eval layer, drives
a benchmark loop, and ships with a single admin console that
configures all four.

## What's in this release

- **One Go binary.** Runs against any Postgres, ClickHouse, and
  Redis instance, and ships its console embedded.
- **OpenAI-compatible chat completions** — including streaming —
  reachable from any OpenAI-shaped SDK by changing `base_url`.
- **A console** that drives every layer: configuration of the
  gateway, the eval rules, the quality-aware router's weights, and
  benchmark launches.
- **An eval layer** that scores every trace, with two on-by-default
  in-process heuristics (PII, completeness) and a plugin contract
  that forwards traces to nine vendor evaluators.
- **A benchmark integration** that runs models against hosted
  evaluation suites on Prime's hosted-verifier platform, and
  feeds the most-recent settled run back into the quality-aware
  router.
- **SSO via OIDC** so a new team joins a shared instance without
  a stand-alone identity layer.
